# Adding a New Site | Omeka S
#### [Made by Sara Whitver with Scribe](https://scribehow.com/o/Q5Aaj_WQQLSLiZKvgOpJpw/viewer/Adding_a_New_Site__Omeka_S__4MLaungdQnyh87cuxiBK8Q)
Sites are the public-facing side of an Omeka S installation. With sites you can create content and interpretation around a group of items from your installation.

Tip: 🔗 Check out the Omeka S User Manual:[Sites](https://omeka.org/s/docs/user-manual/sites/#add-a-site)


1\. Start in the project's Administrative Dashboard. You can add a site through the quick link in Manage Sites on the main dashboard page, or you can navigate to the sites landing page by selecting "sites" in the left side menu.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-23/8f87552a-bb6a-4a5c-a575-614787f27391/user_cropped_screenshot_7f6e98712397404184f47d80595c9d9e_text_export.jpeg)


2\. Select the "add new site" button at the top right of the sites landing page.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-23/8881fc4a-d037-4277-954e-80f7c73c7254/user_cropped_screenshot_ba8eea083fbe4ddeacfcc901e8bf6ee3_text_export.jpeg)


Tip: There are two categories of information you will need to provide to create a site: Info and Theme.


3\. [Info](https://omeka.org/s/docs/user-manual/sites/#info-tab) for a site includes the site's title and an optional custom (user-friendly) slug.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-23/edcccca4-e40b-4c6b-b420-6b307e380b8e/user_cropped_screenshot_dadbcf068b11472bb6f8e74069329225_text_export.jpeg)


4\. The second category of of information you can enter when creating sites is selecting a theme. Before a theme can be selected, it must be installed; talk to the Digital Humanities Librarian if you want to change or update your site theme. Otherwise, use the default.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-23/657fd165-5a3b-49f6-b458-254eb029b76c/user_cropped_screenshot_a912dc9f600c4b6a9ea47e69d9aba4fb_text_export.jpeg)


5\. Once you have input all of the information in the info and theme tabs, select "add" to create your new site.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-23/00fd6ea2-eb59-4bc3-b9b6-a87a5007918e/user_cropped_screenshot_8408ef64d9eb479a87471a9949e2229b_text_export.jpeg)


Tip: Hooray! You have created a new site. See the guide "Editing an Omeka S Site" for more information about how to build and revise your site!
