# Create a New Resource Template | Omeka S
#### [Made by Sara Whitver with Scribe](https://scribehow.com/o/Q5Aaj_WQQLSLiZKvgOpJpw/viewer/Create_a_New_Resource_Template__Omeka_S__CcvTf0KMRJWg3xXMQQkpZg)
A resource template is a set of pre-defined properties, optionally with a Class, to guide item creation and the interpretation of properties.

Tip: 🔗 Check out the Omeka S User Manual: [resource template](https://omeka.org/s/docs/user-manual/content/resource-template/)


1\. From the administrative dashboard of your project, select "Resource template" from the list of Resources in the left menu.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/16efb1e0-8a80-4f33-b8e2-439952a10190/user_cropped_screenshot_0504c0fbe9f147c78c5c6fd6f9a2e63d_text_export.jpeg)


2\. On this page, you will see a list of the resource templates that already exist in this project, along with an option to Import or create additional resource templates. A project can have any number of resource templates.

To create a new resource template, find the button at the top right of the page that says "add new resource template."

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/0f6ea562-7c88-47cd-a72c-acb4c4aec466/user_cropped_screenshot_9b5e53210278449e90a90073a813d544_text_export.jpeg)


3\. You will need a label and an optional choice of class when you create a new resource template. The label is the name of the template that will show up in the list of resource templates, so be mindful when you name it.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/8fa82633-edac-4a86-b286-dbfbb899c7d1/user_cropped_screenshot_63e3d11d97124412bfe62d2fac2196fe_text_export.jpeg)


4\. Class is optional. Choosing a class will enhance your ability to filter by class field when searching and browsing, but especially with smaller collections or collections that do not have a variety of types of items, class is irrelevant.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/829b0713-8cae-4b0d-8836-adc199a227f9/user_cropped_screenshot_4e8d6119f670465b87a132d8723ea3a7_text_export.jpeg)


5\. In the project Cats that Live in Houses, we are applying "person" to the biographical profile content of each cat.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/e873bb23-249a-4092-9b32-af557f4eea63/user_cropped_screenshot_2868335ea2f84a5aa6c466b3ecb462e9_text_export.jpeg)


6\. After adding a label and (optionally) a class, you can begin to add fields to the template. You can only add already existing fields from the vocabularies already installed in the project.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/fca025ee-cfe7-43b1-a219-4f08ebd96e4c/user_cropped_screenshot_f908632a9de14644b5a38c2a29759eae_text_export.jpeg)


7\. In the new "Cats not Inside House" resource template, we need to add the "nickname" field from the vocabulary "Friend of a Friend."

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/df34e7be-33d9-48d9-adbd-60f99ee6713b/user_cropped_screenshot_18702a46371545cc81523281f7990928_text_export.jpeg)


8\. We will also add the Dublin Core "relation" field, so that we can relate the cat profile back to the team member who is related to that cat.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/f0e122f7-a737-45f6-b252-c62d373084ae/File_193b89c1fd364ee79d810c29b98bc420_text_export.jpeg)


9\. When you are finished adding fields, save the template by selecting the "add" button on the top right of the screen

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/96f3d54d-fee0-4698-bff8-05892c6fe960/user_cropped_screenshot_bccaba6fde934390bcfc303907b5e263_text_export.jpeg)


10\. And HOORAY! You made a resource template!

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/0482c0ef-c55a-4bfe-8f96-92ab4a24cbe5/user_cropped_screenshot_34c6bef597db4d01bf66355cc670e9a4_text_export.jpeg)


11\. "Cats not Inside Houses" now sits in the list of available resource templates for this project, and it is ready to be used!

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/a6b8e6f7-4d13-4389-8153-113e3ad6fe2f/user_cropped_screenshot_52e7cdf91cc3489b954f6e866f721cb4_text_export.jpeg)
