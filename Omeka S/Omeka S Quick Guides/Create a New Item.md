# Create a New Item | Omeka S
#### [Made by Sara Whitver with Scribe](https://scribehow.com/o/Q5Aaj_WQQLSLiZKvgOpJpw/viewer/Create_a_New_Item__Omeka_S__2Vm_olZ6SsemTKfeYLhpPA)
Items don't have to represent physical objects (photographs, maps, books), nor do they have to have attached media (a scan of a photo, or multiple page images, or a PDF). An item can be used as a node - a way to represent a person, place, or thing. You can use items and their classes to create separate types of nodes that serve the purposes of your sites.

Tip: 🔗 Check out the Omeka S User Manual:[Items ](https://omeka.org/s/docs/user-manual/content/items/#items)


1\. Navigate to the Items link using the resources menu on the left of the page, or the quick link in the "manage resources" menu on the administrative dashboard homepage.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/b4a2b7b9-f10a-49f5-a6a8-32ceacc08ceb/user_cropped_screenshot_8b9b06200b2548649c367df69e1e094b_text_export.jpeg)


2\. Select the "Add new item" button on the top right corner of the *Items* page.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/c3fcc067-03a0-4ca3-b2f3-761f36b1af29/user_cropped_screenshot_a3ba3e4d319745a9ac47c1fe71c685e3_text_export.jpeg)


Tip: There are 5 different categories of information you need to include in your item record: **Values**, **Media**, **Item Sets**, **Sites**, and **Advanced**. The only required category is Values.


3\. The [Values](https://omeka.org/s/docs/user-manual/content/items/#values) category includes the descriptive "metadata" fields for the individual item.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/97924127-6a09-4f60-a3ea-e05a5ded0cf0/user_cropped_screenshot_43af664eeec5414f9baa9442e1cb4b6f_text_export.jpeg)


4\. Each item can be associated with one single Resource Template. The resource template will automatically create the associated fields for you.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/24a2500c-ce3c-43ea-b559-c4b52618f3ba/user_cropped_screenshot_c76c45208736419cbd36cf88f2635d60_text_export.jpeg)


5\. For this demonstration, we will select "Cats not Inside Houses"

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/597fee56-d766-4bc3-af77-439386e9a90e/user_cropped_screenshot_ae18c2ade94a40cd8ace0fe1d26c840d_text_export.jpeg)


6\. Notice that in addition to the default fields "Title" and "Description," we now have two more fields: "nickname" and "relation."

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/80f4f82e-4c58-46a8-963f-6678ad51b47e/user_cropped_screenshot_acf82f44f2d54787852d4e839c9e2b8f_text_export.jpeg)


7\. Finish the values category by filling the fields with information about your new item.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/c8127f25-8340-451d-b37f-45ece53d122a/user_cropped_screenshot_f6b0c1b8ed734b25bd7e40b47ad95db2_text_export.jpeg)


Tip: There are three modes of information that can be added to your item record: **Text**, **Omeka Resource**, and **URI**. All three modes of information can be included in one record and multiple instances of each mode can also be included.


8\. [Text fields](https://omeka.org/s/docs/user-manual/content/items/#text) allow for unformatted text entry. No markup is allowed in these fields (e.g. Markdown, HTML).

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/2869f61b-daf7-4e71-a10f-245363f6e92c/user_cropped_screenshot_0c964b0815b84efb8e0bac359a140279_text_export.jpeg)


9\. An [Omeka Resource](https://omeka.org/s/docs/user-manual/content/media/#omeka-resource) that already exists in your project.

The Omeka resource fields create an internal link between the resource you are creating and the resource that fills that field.

You have the option to use either an item or an item set. Choosing a resource type will open a side drawer where you can browse all of those resources in the installation. You can use the search function at the top of the drawer to narrow down the list or to quickly find a specific item or item set.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/519613ab-cd1c-42d1-bcec-5a80087f5052/user_cropped_screenshot_b0296b5cf42c4ab39b1b6ae765b972fb_text_export.jpeg)


10\. [URI fields](https://omeka.org/s/docs/user-manual/content/item-sets/#uri) link to an external website or online resource. Every URI value has the link itself, and an optional textual Label to replace the URI with something human-readable. For example, you may wish to enter in a Creator as a URI to a controlled vocabulary of artists or authors, and then include the creator's name in plain text as the Label. Omeka will not automatically pull information from the URI.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/6a19fcea-85b4-4e1c-8590-648ee049ebd9/user_cropped_screenshot_acd61e79f152472f922a4feaf1e849b7_text_export.jpeg)


11\. The second category of information is "[Media](https://omeka.org/s/docs/user-manual/content/media/)."

Using the buttons on the Add New Media menu on the right side of the screen, select a media type (Upload, URL, HTML, oEmbed, IIIF, or YouTube). Modules, such as File Sideload, can add more ways to gather media into Omeka.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/1080095e-e217-4267-83b3-e5f524b9ca52/user_cropped_screenshot_437cd69e161e412cb0ee76a22ee23230_text_export.jpeg)


12\. You can nest the new item in item sets. An item can belong to more than one item set.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/218e401b-5cf4-4d58-bd91-817b5c30e5c8/user_cropped_screenshot_0f9327f909b54b309e477df168be283b_text_export.jpeg)


13\. Category 4 of information for new items is "[Sites.](https://omeka.org/s/docs/user-manual/sites/)"

Sites are the public-facing side of an Omeka S installation. With sites you can create content and interpretation around a group of items from your installation.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/3fc24cbc-4bcb-4611-882f-242e4b73ee71/user_cropped_screenshot_eef4bc07a38f4079823d4fb23813d378_text_export.jpeg)


14\. The 5th category of information is "advanced" and is optional. The [advanced tab](https://omeka.org/s/docs/user-manual/content/items/#advanced) has two options. One lets you set a custom thumbnail for the item. The other allows you to change which user has ownership of the item.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/e2861d94-d2ee-401a-ad2a-6461917cdbee/user_cropped_screenshot_d43f6f1038214677bc1d3bc0d3bc8ab8_text_export.jpeg)


15\. Once you have completed all of the categories of your item record, it's time to save the item! To do this, select the "save" button on the top right corner of the page.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/868c6587-25df-4af6-ac44-c47251cc8bb3/user_cropped_screenshot_67cde6d1033a404eb4da6edbc1d5bedf_text_export.jpeg)


16\. Hooray! You have created an item in Omeka S!

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/03fce38b-f24e-4a1a-823d-de3b18594da6/user_cropped_screenshot_bc502857e3ce4474959083a1e8660bf6_text_export.jpeg)


17\. If you navigate back to "items" in your resources, you will be able to see your new item!

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2025-09-22/8888ae77-02a4-4831-aa50-38dd5669bca6/user_cropped_screenshot_05e0f284e7d24bf7b9fd156182b68161_text_export.jpeg)
